# Parteneriate date produse

Document de lucru pentru contactarea retailerilor si producatorilor mari.

## Ce cerem

Pentru ca Ce aleg? sa ofere recomandari corecte, avem nevoie de un export periodic cu:

- cod de bare/EAN
- SKU intern, daca exista
- denumire produs in romana
- brand
- categorie si subcategorie
- cantitate/gramaj
- imagine principala produs
- ingrediente
- alergeni
- valori nutritionale per 100 g/ml
- pret curent, optional
- disponibilitate pe magazin/oras, optional
- data ultimei actualizari

Format acceptat: CSV, XLSX, JSON, XML feed sau API. Imaginile pot fi linkuri publice sau un folder/arhiva cu fisiere.

## Mesaj initial

Subiect: Propunere parteneriat date produse pentru Ce aleg?

Buna ziua,

Sunt Nicolae, fondatorul Ce aleg?, o aplicatie web care ajuta clientii sa scaneze produse alimentare, sa inteleaga rapid eticheta si sa compare alternative mai potrivite pentru bugetul si preferintele lor.

Vrem sa imbunatatim calitatea recomandarilor pentru produsele disponibile in magazinele dumneavoastra. Ne-ar ajuta un export de catalog sau un feed cu date de produs: cod de bare/EAN, denumire, brand, categorie, cantitate, imagine, ingrediente, alergeni si valori nutritionale. Daca exista si preturi sau disponibilitate pe magazin, acestea ar fi utile, dar nu sunt obligatorii in prima etapa.

Datele ar fi folosite pentru afisarea corecta a produselor in aplicatie, pentru recomandari transparente si pentru trimiterea utilizatorilor catre alternative relevante din acelasi tip de produs. Nu modificam denumirile comerciale si putem afisa sursa retailerului acolo unde este cazul.

Putem primi datele ca CSV, XLSX, JSON, XML feed sau API, inclusiv intr-un format deja folosit intern. Daca este nevoie, semnam un acord de utilizare a datelor si respectam regulile privind imaginile, brandurile si actualizarea informatiilor.

## Mesaj pentru platforme de date nutritionale

Subiect: Propunere colaborare date produse romanesti pentru Ce aleg?

Buna ziua,

Sunt Nicolae, fondatorul Ce aleg?, o platforma online disponibila la
https://www.cealeg.shop, care ajuta utilizatorii sa compare mai usor produse
alimentare inainte de cumparare.

Ce aleg? functioneaza ca un asistent smart pentru cumparaturi: utilizatorii pot
scana coduri de bare sau pot cauta produse, iar platforma afiseaza un raport
orientativ despre produs si alternative mai potrivite in functie de preferinte
precum mai putin zahar, mai multa proteina, ingrediente mai simple sau raport
calitate-pret mai bun.

In prezent lucram cu un catalog de peste 29.000 de produse, construit din surse
publice si contributii, insa pentru Romania ne intereseaza in mod special date
locale, curate si cat mai apropiate de ce gasesc utilizatorii la raft.

Ne-ar interesa sa aflam daca exista posibilitatea unei colaborari pentru acces la
date nutritionale, categorii de produse sau informatii publice despre produse
romanesti. Ne-ar ajuta in special codul de bare/EAN, denumirea in romana,
brandul, categoria, ingredientele, alergenii, valorile nutritionale si, unde este
posibil, imaginea produsului.

O astfel de colaborare ar ajuta utilizatorii sa primeasca recomandari mai corecte,
iar partenerul de date ar putea fi mentionat ca sursa sau partener acolo unde este
cazul, in functie de termenii agreati.

Putem adapta integrarea la formatul disponibil: CSV, XLSX, JSON, XML feed sau API.
Daca este nevoie, putem discuta si un acord clar de utilizare a datelor.

Multumesc pentru timpul acordat si astept cu interes un raspuns.
